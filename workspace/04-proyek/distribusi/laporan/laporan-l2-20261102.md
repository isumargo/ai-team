## 2. Kenapa bot tadinya cuma "sistem lagi pusing"?

Ada **4 masalah yang menumpuk** — semuanya sudah dibenerin:

| # | Masalah | Kenapa bikin error | Sudah |
|---|---|---|---|
| 1 | Model AI profil dikunci OpenRouter ke mode khusus | Kalau dipanggil biasa (apps Django), server balas **403**. App kita memang pemanggil biasa → **gagal terus** | ✅ |
| 2 | Kode app "menelan" error diam-diam (`except:` kosong) | Error masuk ke mana-mana, jadi user cuma lihat kalimat generik, nggak ada jejaknya | ✅ |
| 3 | Profil Hermes-nya nggak punya kunci API sendiri | Hermes sendiri gagal: "no provider configured" | ✅ |
| 4 | Hermes ikut polling bot yang sama | Bentrok sama webhook → update dobel, memicu error | ✅ |

**Perbaikan:** profil diarahkan ke model gratis yang **terbukti bisa dipanggil normal**, kunci API ditambahkan ke tiap profil, error sekarang ditulis ke log (bukan ditelan), dan polling dimatikan (cuma webhook).
